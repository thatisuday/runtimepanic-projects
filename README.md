# runtimepanic Projects

Companion code for articles published on [runtimepanic.com](https://runtimepanic.com).

Each project lives in `projects/<project-name>` and includes its own setup and run instructions when needed.

## Projects

| Project                                   | Description                                                                                                    |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [`mastra-intro`](./projects/mastra-intro) | AI-powered DevOps status monitor built with Mastra, mock services, agent tools, memory, and workflow examples. |

## Usage

Clone the repository, open the project directory you want, and follow that project's README.

```bash
cd projects/mastra-intro
yarn install
```

## Notes

These projects are examples for blog posts, so they prioritize clarity and learning over production hardening.
